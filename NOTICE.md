# Dependencies and distribution

The MIT license covers this repository's original Outlands scripts, tools,
configuration templates and documentation.

Call of Duty: Black Ops II is a separate commercial game. No game files are
included. Each player and host supplies their own legitimate installation.

Plutonium is a separate dependency obtained from its official updater and
subject to its own terms. Plutonium binaries and upstream game scripts are
not included in this source release. Outlands GSC modules call the installed
runtime's native functions rather than distributing its implementation.

Docker, Wine, Tailscale, Python, Ollama and the Qwen model retain their respective
licenses and terms. Container builds fetch these dependencies separately.
The complete BO2 server image is a private local build and must not be uploaded
to a public registry or attached to a GitHub release.

This is an independent community project, not an official Activision,
Treyarch, Plutonium, Tailscale or Ollama product.
